# LifeDesk demo video script — target 2:30–2:45

## 0:00–0:20 — Problem
“Important documents create work after you read them. You still need to find the deadline, decide what comes first, write a response and remember to follow up. Most assistants stop at a summary. LifeDesk continues to action.”

Show the LifeDesk landing page and the clearly labelled “Alexa+ simulation” badge.

## 0:20–0:35 — Alexa+ simulation concept
“LifeDesk is a simulated Alexa+ experience. The user can ask: ‘Alexa, what do I need to do about this letter?’ The agent keeps the document context and coordinates a multi-step workflow.”

## 0:35–1:45 — End-to-end workflow
Start the Vehicle finance notice and run the guided demo.

Narration as stages appear:
- “First, LifeDesk extracts facts and the deadline.”
- “Then it explains the request in plain language.”
- “It converts that understanding into an ordered action plan.”
- “Next it drafts an editable response.”
- “The draft is editable and retained in this tab. Reminders are suggestions; no calendar is connected.”
- “Finally, the audit trail shows the source fact, the agent’s inference and the proposed action.”

## 1:45–2:05 — Generalisation
Switch to the warranty or appointment example.
“The same controller handles three predefined sample contexts. This is a deterministic prototype; it does not parse a new document or call real Alexa.”

## 2:05–2:25 — Safety/privacy
“All judge examples are synthetic. No private document, account or payment is required. LifeDesk does not replace legal, financial or medical professionals, and production actions would require explicit approval.”

## 2:25–2:45 — Close
“LifeDesk moves assistants from ‘here is what the document says’ to ‘here is what happens next — and why.’ That is the Alexa+ experience we want to make useful in everyday life.”

End on the live demo URL and project name.
